# Campus Navigation Project

A campus navigation system that finds the best route between locations and shows it on an interactive dashboard.

## Features
- Pathfinding engine in Python that computes routes between campus locations
- Interactive HTML dashboard to choose a start and destination
- Step-by-step directions with the route drawn on a map
- Command-line demo to test the engine

## Project Structure
```
campus_nav_project/
├── pathfinding_engine.py       # Core routing logic
├── demo.py                     # Demo script for the engine
├── interactive_dashboard.html  # Web dashboard (map + directions)
└── .gitignore
```

## How to Run

**1. Clone the repository**
```
git clone https://github.com/GovardhanGoud7/campus-nav-project.git
cd campus-nav-project
```

**2. Run the demo**
```
python demo.py
```

**3. Open the dashboard**
Double-click `interactive_dashboard.html`, or open it in any browser.
